# Brand Shop — Link in Bio

پەڕەیەکی سادە و مۆبایل‌گونجاوە، ئامادەی GitHub Pages. بەشی بەرهەمەکان وێنەی کاڵا لە پەیجی فەیسبوکی Brand Shop نیشان دەدات و بە ئاسۆیی دەجوڵێت.

## ناوەڕۆک

- index.html — پەڕە و ستایلی سایت
- assets/brand-shop-logo.png — لۆگۆی 3D و شەفاف
- assets/product-01.jpg تا assets/product-04.jpg — نمونەی بەرهەمەکان
- وێنەکان بە ڕێگەی پەیجی فەرمی Brand Shop وەرگیراون.

## بڵاوکردنەوە لە GitHub Pages

1. ZIPەکە هەڵبشێرە.
2. فایلەکانی index.html و فۆڵدەری assets لە root ـی GitHub repository دابنێ.
3. لە repository ـەکە بچۆ بۆ Settings → Pages.
4. لە Build and deployment، Deploy from a branch، برانچی main و فۆڵدەری /(root) هەڵبژێرە، پاشان Save بکە.
5. دوای چەند خولەکێک، لینکی سایتەکە لە هەمان بەشی Pages دەردەکەوێت.

لینک و ژمارەکان لە index.html دەستکاری بکە و commit/push بکە. QRی واتساپ لەم وەشانەدا نییە؛ لەبری ئەوە، لینکە ڕاستەوخۆکانی واتساپ، تێلێگرام و ڤایبەر دانراون.
